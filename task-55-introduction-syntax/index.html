What is HTML5?

HTML5 is the standard markup language used to structure content on web pages.

HTML5 Semantic Tags

Semantic tags clearly describe the purpose of their content.

  • <header> - Defines introductory content.
  • <nav> - Defines navigation links.
  • <main> - Defines the main content.
  • <section> - Defines a section of content.
  • <article> - Defines independent content.
  • <aside> - Defines related side content.
  • <footer> - Defines footer information.

Important HTML Tags

Common tags include headings, paragraphs, links, images, lists, tables, forms, and semantic elements.

Basic HTML Syntax

HTML elements generally use an opening tag, content, and a closing tag. 


<p>This is a paragraph.</p>

<h1>This is a heading.</h1>

<a href="https://example.com">Visit Website</a>
