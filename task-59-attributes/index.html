Common Attributes Used

  • id: Identifies a unique element.
  • class: Groups elements for styling.
  • title: Provides additional information.
  • style: Adds inline styling.
  • lang: Defines the language of content.
  • hidden: Hides an element.
  • data-*: Stores custom data.
